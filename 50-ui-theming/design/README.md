# 设计稿

五张艺术板，覆盖从登录到设置的核心界面，配两块便签批注。

## 内容

| 艺术板 | 文件 | 内容 |
|---|---|---|
| Main | `Main.dc.html` | 登录页 |
| Repos | `Repos.dc.html` | 仓库列表 |
| Code | `Code.dc.html` | 代码视图 |
| System | `System.dc.html` | 界面规范（字号/间距/圆角/配色一览） |
| Settings | `Settings.dc.html` | 设置界面 |

## 怎么打开

- **`canvas.html`**：整份画布，五张艺术板 + 两块便签批注一次性铺开。
  **双击可离线打开**——已经在真实浏览器里验证过。
- 单个 `.dc.html`（比如 `Main.dc.html`）也能独立打开渲染，同样验证过。

## 已知限制

**无头浏览器渲染不出艺术板内容**——`file://` 和 `http://` 两种方式都试过，
等到 90 秒依然是空白。这是**无头环境本身的限制，不是文件的问题**：同一份
`canvas.html` 在真实浏览器里打开完全正常。判断"是文件坏了"之前先确认自己
用来验证的工具本身适不适用，见
[00-principles.md #4](../../00-principles.md#4-工具缺失会伪装成事实)。

也因为这条限制，本节的设计稿**不走**
[`../../tools/screenshot-pipeline/`](../../tools/screenshot-pipeline/) 那条
无头截图管线——那条管线是给实际部署的 Forgejo 页面用的，对 `.dc.html`
这种画布格式不适用。要看设计稿，直接在真实浏览器里打开文件。

## 其他文件

`canvas.json` 是布局清单——每张艺术板的位置、尺寸、对应页面，以及两块便签
批注的内容和坐标。改布局或加新艺术板时先改这份清单。
